# Pending photos

Card RC-119, DECISIONS.md W14-19. Every image slot the wave 14 audit classes
**RC photo only** (audit section 5): slots that make a proof claim, so only a
photograph or video of Rapid Construct's own work, crew or clients can fill them.
Stock and visualisations are not permitted here (master plan section 7, as
amended by W14-18).

**How to use this list.** Shoot or collect the photo, name the file by the site
file name where one is given, and drop it into `photos-raw/`. Every file also
needs its row in `docs/assets/PROVENANCE.md`.

**Columns.** *Slot ID* is the audit's. *Page* is where the slot belongs on
rapidconstruct.md. *Host on the site* says whether a component exists to show it
today. *Aspect* is the one the photo must be cropped to.
