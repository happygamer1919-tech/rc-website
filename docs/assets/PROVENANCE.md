# Asset provenance

Ruling R-W (`docs/rulings/R-W.md`). Every image under `public/` has exactly one
row. `node scripts/check-asset-provenance.js` fails on an image with no row, on
a row for a file that does not exist, on an empty cell, and on any source URL
whose hostname is fatade3d.md, imperlux.md or dasterum.md.

**Adding an image means adding its row in the same commit.** A row dated on or
after 2026-09-15 must record a real source, licence and licence URL. The value
`unrecorded before R-W` is accepted only on rows dated before R-W.

**What the rows below are, and are not.** They were compiled at W14-02 from what
`DECISIONS.md` already recorded about each file, and nothing else. Where the
record names a source, the row names it. Where it does not, the row says so. The
`date` column is the date of the commit that last changed the file, which is
when the current bytes entered the repo. For most photo slots that is later than
the slot itself, because a placeholder at the same path came first.

**The licence gap is real, and it is the finding.** Of 149 images, only the
five Wikimedia Commons logos and the files generated in this repo have a
recorded licence. The client photographs are assumed to be the client's own
work, but no licence or release was ever written down. The supplier logos from
brand websites are trademarks shown to name a supplier, with no recorded terms.
Recorded as open in `docs/QUESTIONS.md`, Q-W14-01.
