# W28-06 · The form

Card W28-06. Branch `w27/w28-06-form`, stacked on W28-05.

## What changed

The quote form's fields are cream with an edge you can see, taller (56px), with rounder corners;
labels are plain 16px text instead of small orange capitals; the send button spans the form. The
contact column beside it is a list (the big orange phone number, the hours, the note) instead of two
boxes. Filter buttons on the roofing page get the same clear edge. Nothing about where the form sends
changed.
